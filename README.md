# AngioMorph

Инструменты для анализа коронарных ангиограмм созданным маскам нейросети:

- построение центральной линии сосуда;
- перевод маски в граф сосудистого дерева;
- поиск бифуркаций, наложений и коротких артефактов скелета;
- статистика по ветвям, узлам, яркости и градиентам;
- темпоральный анализ узлов по сериям кадров;
- визуализация overlay-картинок, видео и отчётов.

## Основной пайплайн

### `3d/yolo_angiomorph_pipeline.py` — **ГЛАВНЫЙ СКРИПТ**

Полный end-to-end пайплайн анализа ангиограмм:

1. Загружает изображения из указанной папки
2. Сегментирует сосуды с помощью YOLO (обученная модель)
3. Автоматически строит граф сосудистого дерева через `analyze_coronary_graph.py`
4. Классифицирует бифуркации, наложения и артефакты
5. Собирает финальное видео с визуализацией

**Запуск:**
```python
from yolo_angiomorph_pipeline import create_image_pipeline

create_image_pipeline(
    input_dir="/path/to/images",           # папка с DICOM/PNG кадрами
    yolo_weights_path="/path/to/best.pt",  # веса обученной YOLO модели
    output_video_path="output.mp4",        # итоговое видео
    fps=10                                 # кадров в секунду
)
