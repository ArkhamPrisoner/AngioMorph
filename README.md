# AngioMorph

Инструменты для анализа коронарных ангиограмм по ручным маскам:

- построение центральной линии сосуда;
- перевод маски в граф сосудистого дерева;
- поиск бифуркаций, наложений и коротких артефактов скелета;
- статистика по ветвям, узлам, яркости и градиентам;
- темпоральный анализ узлов по сериям кадров;
- визуализация overlay-картинок, видео и отчётов.

## Основные скрипты

- `3d/analyze_coronary_graph.py` — анализ одной пары `image + mask` или пачки кадров.
- `3d/analyze_patient_context.py` — сводка по пациентам, сериям и анатомическому шаблону.
- `3d/build_review_candidates.py` — очередь кадров для ручной проверки.
- `3d/build_temporal_junction_analysis.py` — отслеживание узлов во времени.
- `3d/reconstruct_coronary_tree.py` — прототип псевдо-3D реконструкции из маски.

Подробности запуска находятся в `3d/README_reconstruction.md`.

## Результаты

Текущие отчёты и визуализации лежат в:

```text
3d/outputs_graph_analysis/
```

Там есть:

- overlay-картинки с графом и легендой;
- видео `manual_all/videos/manual_all_overlays.mp4`;
- таблицы CSV;
- отчёты Markdown;
- графики темпоральной устойчивости узлов.

## Данные

Сырые медицинские данные, архивы, DICOM, обученные модели и тяжёлые промежуточные артефакты не включены в репозиторий. Они остаются локально и исключены через `.gitignore`.
